# ITCC45 classroom pilot worksheet

Use one row per learner/example. Do not record names, student numbers, grades,
or other identifiers. The purpose is to improve explanations, not evaluate the
student.

## Observation

1. **Prediction before playback:** What does the learner expect to change or print?
2. **Explanation after playback:** Ask the learner to explain the important
   reference, lookup, or state change in their own words.
3. **Transfer prompt:** Change one name/value or describe how the same idea would
   appear in a different setting.
4. **Observed hesitation or misconception:** Record the specific step, label, or
   diagram relationship—not a judgement about the learner.
5. **Completion time:** Record an approximate duration.
6. **Outcome:** clear / partial / still confused.
7. **Suggested revision:** wording, source length, step ordering, diagram
   evidence, or practice alignment.

## Review rule

Reopen an example when two or more learners misread the same causal step. Prefer
the smallest correction that makes that step observable, then rerun the example
and its Python-output and accessibility checks before changing the portfolio.
