Pseudocode Grammar

The commands the checker understands. Keywords are not case-sensitive.

Input, output, assignment

READ x
WRITE x
WRITE "some text"
x <- 10
x <- a + b

The arrow <- stores the value on the right into the name on the left.

Selection

IF condition THEN
    statement
ELSE IF condition THEN
    statement
ELSE
    statement
ENDIF

Conditions are checked in order. The first true one wins.

Repetition

FOR i <- 1 TO n DO
    statement
ENDFOR

WHILE condition DO
    statement
ENDWHILE

Values and operators

TRUE  FALSE     booleans
+  -  *  /  %   arithmetic
=  <>  <  >  <=  >=
AND   OR   NOT
# comment

Two things that catch people out

ELSE IF condition THEN continues the same decision chain. An IF on the following indented line starts a genuinely nested decision inside the ELSE block.

Output must match exactly. WRITE "INVALID" passes; WRITE "Invalid." does not.
