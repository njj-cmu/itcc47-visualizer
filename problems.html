Pseudocode grammar

The commands the checker understands. Keywords are not case-sensitive.

Input, output, assignment

READ x
WRITE x
WRITE "some text"
x <- 10
x <- a + b

The arrow <- stores the value on the right into the name on the left.

Selection

IF condition THEN
    statement
ELSE IF condition THEN
    statement
ELSE
    statement
ENDIF

Conditions are checked in order. The first true one wins.

Repetition

FOR i <- 1 TO n DO
    statement
ENDFOR

WHILE condition DO
    statement
ENDWHILE

Values and operators

TRUE  FALSE     booleans
+  -  *  /  %   arithmetic
=  <>  <  >  <=  >=
AND   OR   NOT
# comment

Two things that catch people out

A bare IF right after ELSE reads as ELSE IF. If you need a nested IF as the first line of an ELSE block, put an assignment above it first.

Output must match exactly. WRITE "INVALID" passes; WRITE "Invalid." does not.
