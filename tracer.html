Pseudocode Grammar

The commands this tracer understands. Keywords are not case-sensitive.

Input, output, assignment

READ x
WRITE x
WRITE "some text"
x <- 10
x <- a + b

The arrow <- stores the value on the right into the name on the left. You may also type ←.

Selection

IF condition THEN
    statement
ELSE IF condition THEN
    statement
ELSE
    statement
ENDIF

Conditions are checked in order. The first one that is true wins.

Repetition

FOR i <- 1 TO n DO
    statement
ENDFOR

FOR i <- n DOWNTO 1 STEP 2 DO
    statement
ENDFOR

FOR EACH item IN list DO
    statement
ENDFOR

WHILE condition DO
    statement
ENDWHILE

STEP must be a positive whole number. Use TO or DOWNTO to choose direction.

CASE

CASE choice OF
    1:
        WRITE "Start"
    2:
        WRITE "Load"
    DEFAULT:
        WRITE "Invalid"
ENDCASE

Stopping early

BREAK     leave the loop
RETURN    leave with a value
STOP      end the algorithm

Two things that catch people out

ELSE IF condition THEN continues the same decision chain. An IF on the following indented line starts a genuinely nested decision inside the ELSE block.

/ is integer division and floors the result, matching the way the lecture halves n at each step of a binary search.
