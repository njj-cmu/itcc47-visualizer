Pseudocode grammar

The commands this tracer understands. Keywords are not case-sensitive.

Input, output, assignment

READ x
WRITE x
WRITE "some text"
x <- 10
x <- a + b

The arrow <- stores the value on the right into the name on the left. You may also type ←.

Selection

IF condition THEN
    statement
ELSE IF condition THEN
    statement
ELSE
    statement
ENDIF

Conditions are checked in order. The first one that is true wins.

Repetition

FOR i <- 1 TO n DO
    statement
ENDFOR

FOR EACH item IN list DO
    statement
ENDFOR

WHILE condition DO
    statement
ENDWHILE

CASE

CASE choice OF
    1:
        WRITE "Start"
    2:
        WRITE "Load"
    DEFAULT:
        WRITE "Invalid"
ENDCASE

Values and operators

[3, 8, 15]      list
values[2]       list position
TRUE  FALSE     booleans
+  -  *  /  %   arithmetic
=  <>  <  >  <=  >=
AND   OR   NOT
# everything after # is a comment

Stopping early

BREAK     leave the loop
RETURN    leave with a value
STOP      end the algorithm

Two things that catch people out

A bare IF right after ELSE reads as ELSE IF. If you need a genuinely nested IF as the first line of an ELSE block, put an assignment above it first.

/ is integer division and floors the result, matching the way the lecture halves n at each step of a binary search.
